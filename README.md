# パワータワー 🦸🗼

広告でよく見る「タワーバトル」系のブラウザゲームです。
自分より**弱い**敵（数字が緑）をタップして倒すと、その数字ぶんパワーが増えます。
強い敵（数字が赤）に挑むと負け。**ボスを倒して**、塔の上のお姫様を助けたらクリア！
ほかの部屋は寄り道自由。寄り道してパワーを集めるほど★が増え、全部屋を回ってからボスを倒すと **PERFECT**（金貨ボーナス）。

**移動ルール**：部屋どうしは**橋（隣の塔の同じ階）**と**はしご（同じ塔の上下）**がある所だけつながっています。
進めるのは通った場所とつながった部屋だけ。一度通った場所は自由に行き来できます。行ける部屋は光り、まだ行けない部屋は暗く表示されます。
ステージが進むと通路が減って迷路のようになり、罠を踏まないとボスに届かない道も出てきます。

| マス | 効果 | コツ |
|---|---|---|
| 敵 | 倒すと +数字 | 小さい数字から |
| 🧪 `+N` | パワー +N | いつでもOK |
| ✨ `×2` | パワー 2倍 | **大きくなってから**取るほどお得 |
| 💣 `÷2` | パワー 半分。ただし**つながった隣の敵をまとめて吹き飛ばして吸収**（強さ関係なし、ボス以外） | 強い敵のそばで使う |
| ☠ `−N` | パワー −N | 弱いうちに取ると**力尽きる** |
| ❓ `？` | 開けるまで分からない | ×2 / +40% / 金貨 / 半分 / −25% のどれか（開けて即負けはしない） |

- 最後のパワーが大きいほど ★1〜3。金貨がもらえ、ショップでヒーローを強化できます
- ステージは横に広く、スワイプで見渡せます。1手戻す（↶）も使えます
- 10レベルごとにワールド（草原 → 砂漠と海 → 氷と天空 → 地底と火山 → 魔王城）が変わります

**遊ぶ:** https://machino-ai.jp/power-tower/ （スマホで「ホーム画面に追加」するとアプリのように遊べます）

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面の骨組み・見た目 |
| `js/config.js` | **調整値はここ**（難易度・罠の数・★の基準・ショップ・ワールド） |
| `js/level.js` | レベル生成（必ずクリアできる）と★評価用の最高スコア計算 |
| `js/audio.js` | 効果音と BGM（WebAudio で生成、音声ファイルなし） |
| `js/game.js` | ゲーム本体（画面・カメラ・タップ処理・タイトル/ショップ） |
| `img/` | ゲームで使う軽い画像（`tools/optimize.py` で `assets/` から自動生成） |
| `assets/` | 素材の原本 201点（一覧は `assets/README.md`） |
| `sw.js` / `manifest.json` | ホーム画面追加・オフライン対応（PWA） |
| `BRUSHUP.md` | 改善アイデア・TODO リスト |
| `CLAUDE.md` | Claude Code に作業してもらうときの指示書 |

ビルド不要。`index.html` をブラウザで開くだけで動きます。
`index.html?lv=8` のように付けると、タイトルを飛ばしてそのレベルから始まります（テスト用）。

## 2台のPC（メインPC / 4thPC）で共同編集する手順

### 最初の1回だけ（4thPC側）

```bash
gh auth login
gh repo clone mitsukenn/power-tower
```

### 毎回の作業の流れ（どちらのPCでも同じ）

1. **作業前に最新を取り込む** … `git pull`
2. 編集する（Claude Code に「BRUSHUP.md の〇〇をやって」と頼んでもOK）
3. **作業後に保存して送る** … `git add -A` → `git commit -m "変更内容"` → `git push`

push すると 1〜2 分で公開URLにも反映されます。

> 同じファイルを両方のPCで同時に編集すると「コンフリクト」が起きることがあります。
> 作業前の `git pull`、作業後の `git push` を習慣にすれば、ほぼ防げます。
